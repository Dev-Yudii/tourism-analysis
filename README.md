# tourism-analysis

### Brazil Tourism Evolution (1989 - 2024)
This project aims to analyze the historical evolution of international tourism in Brazil over the last 35 years.

Project Phases:
- Phase 1 (Completed): Exploratory analysis of the 1989 legacy dataset. Focus on understanding data structure and historical patterns.

- Phase 2 (In Progress): Building a scalable ETL pipeline to process and consolidate data from 1989 up to 2024.
